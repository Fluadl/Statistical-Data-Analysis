# Multivariate Statistical Analysis and Hypothesis Testing

This project contains exercises and analyses related to multivariate statistical methods and hypothesis testing using R.

## Topics Covered

- Covariance matrix estimation
- Mahalanobis distance
- Hotelling’s T² test
- Confidence regions for multivariate hypothesis testing
- Visualization of high-dimensional data
- Scatterplot matrices and statistical projections
- Exploratory multivariate data analysis

## Technologies

- R
- Multivariate statistics
- Data visualization

## Project Goal

The goal of this project was to apply statistical methods to multivariate datasets, analyze relationships between variables, and perform hypothesis testing in higher-dimensional settings.

The exercises focus on both theoretical statistical concepts and practical data analysis workflows.
